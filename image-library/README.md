# AfghanTours photography library

- `originals/`: files exactly as supplied, never edited. They are checked by SHA-256 against the files James sent.
- `candidates/`: optimised WebP versions (1600 px and 800 px on the long side, quality 80). They are **not** used on any page yet.
- `register.csv`: one row per photo. Location, photographer, owner and licence stay "unverified – ask James" until he confirms them or EXIF GPS proves them.
