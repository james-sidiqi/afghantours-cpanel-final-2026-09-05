# Website Standards

## UX
- Never auto-scroll users.
- Never auto-snap users to content.
- Only scroll when initiated by explicit user action.

## Carousels
- Infinite looping.
- Bi-directional.
- No visible reset.
- First item follows last item seamlessly.

## Cards
Preview → Popup → Full Page

## Design System
- No adjacent major sections share the same background color.
- No three consecutive sections use the same layout pattern.
- Every section requires a visual anchor.
