# AfghanTours.com — Content Guidelines for Agents

Use this file before writing, editing, or generating any public copy for afghantours.com.

This is a content-only rulebook. Do not change URLs, layouts, CSS, JavaScript, Astro architecture, data models, or deploy anything unless a separate technical brief says so.

If a rule here conflicts with a flashy draft, this file wins.

---

## 1. What the company is

AfghanTours.com is the public site of **James Tourist & Travel Agency**, a licensed Afghan tour operator based in Kabul.

Positioning:

- knowledgeable
- grounded
- credible
- respectful
- culturally informed
- professional
- locally connected
- reassuring without guarantees
- premium without luxury theater
- adventurous without sensationalizing Afghanistan

The product is meaningful access: cultural, historical, heritage, and specialist journeys. It is not “dangerous adventure tourism.” Safety and logistics should create confidence. They must not become the whole brand.

Intended readers: curious travelers, photographers, historians, academics, researchers, former diplomats and development staff, Afghan diaspora, people who care about Silk Road history, architecture, food, crafts, and ordinary Afghan life.

## 3. Hard rules

### Never invent

Do not invent or guess:

- prices, deposits, cancellation terms, payment methods
- inclusions / exclusions (except the locked LOI line)
- tour dates, seasons as guarantees, opening hours
- exact drive times presented as fixed
- hotel star ratings or amenity lists
- vehicle models as standard
- guide qualifications, staff headcount, traveler numbers
- partnerships, embassy relationships as endorsements
- customer quotes, reviews, media coverage
- visa guarantees, government approvals
- security guarantees or named security procedures
- new tour names or URLs
- that a destination is “always included” on a tour

If the fact is missing, write:

`[OWNER INPUT REQUIRED: exact question]`

Leave the marker visible. Do not smooth over the gap with atmosphere.

### Never overpromise safety

Banned:

- safe / safest / completely safe / guaranteed safe
- secure journeys / highly secure / high-security
- risk-free / absolute security / guaranteed protection
- historically safe
- peacetime / peacetime reality
- we will keep you safe
- safety-first operations (as a slogan)
- real-time monitoring / vetted daily (unless the owner writes the public sentence)

Approved substitutes:

- planned / route-aware / conditions change
- local coordination
- access is assessed before departure
- if a pass is the wrong call that week, we use another road or we wait
- Travel in Afghanistan carries inherent risk; planning is reviewed as conditions change

Travelers should be told to read their own government’s advisory. Insurance that actually covers Afghanistan is the traveler’s responsibility unless the owner later requires it in public copy.

### Never use generic AI travel language

Banned examples (not a complete list — if it could sit on any destination site, cut it):

- unforgettable / once-in-a-lifetime / bucket-list
- hidden gem / vibrant tapestry / rich tapestry
- embark on a journey / discover the magic
- where history comes alive
- breathtaking at every turn
- ultimate adventure / the tour that changes everything
- leave with stories, not just photographs
- change the way you see the world
- seduces you slowly / commands your silence
- pinnacle of luxury / crown jewel (unless already a historic epithet like Pearl of Khorasan)
- Grand Canyon of Afghanistan
- world’s largest / most trusted / premier

Write the specific thing: the empty niche, the Friday Mosque tile, chapli at a named place you are allowed to list, the long highland road.

### Never sensationalize Afghanistan

Do not frame the country as forbidden, extreme, thrill-seeking, or “one of the most dangerous places on earth.”

Do not write conflict tourism. When 2001, the Soviet period, or a valley’s political history is relevant, say it in one sober clause. Do not use destruction or war as atmosphere.

Do not write “iconoclasts” as a coy stand-in for the 2001 Buddha destruction. Either name the year or leave the destruction out of the sentence.

### Never leak the CMS

Delete from public pages:

- `itinerary CSV`
- `Inquire Days`
- `$Inquire`
- `Inquire days of guided travel`
- lorem, TBD, TODO, placeholder, dummy, sample itinerary

### Never change architecture under a content brief

Do not:

- invent new tour slugs
- invent new destination URLs
- add emoji trust bars or new widgets
- rename files or routes
- “fix” a missing tour by creating a page to match the copy

Copy follows the live site. The live site does not follow a draft.

## 4. Voice

Write like a competent operator in Kabul, not a travel magazine and not a security firm.

Do:

- short sentences
- concrete nouns
- present tense for how the company works
- allow a place to be ordinary (tea, traffic, a long drive)
- keep one good image per paragraph, not three
- end pages on a live tour, custom expedition, or WhatsApp

Do not:

- stack epithets in the H1, subhead, and first sentence
- use emoji in body copy
- write “we get the question before we hear it”
- toast the guest (“we will treat you like family / we will feed you well”)
- use “favela-esque,” “petrified scream,” or other borrowed drama

Approved lines (reuse; do not dilute):

- Not the headlines. The hospitality. The history. The highlands.
- We do not sell fantasy itineraries.
- We monitor the roads so you can watch the mountains.
- Afghanistan is not a checkbox. It is a conversation.
- Direct local operators — no middlemen, no guesswork.

## 6. Page recipes

### Homepage

Say who you are, where you work, and what you will not pretend.

Must include: licensed Kabul operator, American-led, ATO-KBL-1617, LOI on booked tours, no fantasy itineraries.

Must not include: most trusted, secure journeys, armored vehicles as a pillar, visa included, traveler stories, emoji trust bar.

CTAs: `/tours/` and `/tours/custom-expedition/` plus WhatsApp.

### Destination / province pages

Pattern:

1. Place name as H1 (not a poem)
2. One-line subhead that names the actual things
3. Short overview (what you see / how the days feel)
4. Logistics as facts: season, how people usually arrive, pace
5. Live tours only
6. CTA to WhatsApp or a live tour

Do not add a “Security: …” row. Planning notes belong in prose: conditions vary; access is assessed.

Ghor / Jam: seasonal caveat is mandatory. Link `/destinations/ghor/`, `/attractions/minaret-of-jam/`, and `/tours/custom-expedition/`. No fake Jam tour.

Panjshir: landscape, hospitality, emerald towns if relevant. History may be mentioned. It may not be sold as safety.

### Tour pages

Keep the live day-by-day spine if one exists. Rewrite sentences. Do not invent a new route.

For Central Afghanistan Discovery the live spine is:

1. Arrive Kabul
2. Road to Bamyan (pass chosen that week)
3. Bamyan valley (niches, Gholghola, Zohak)
4. Band-e-Amir if conditions allow; else more Bamyan
5. Return to Kabul
6. Kabul day
7. Depart

Specialist pages (Veteran Return, Media Support, Business Investment, Ski, Noshaq, Scientific, Photography):

- do not claim highly secure / peacetime
- do not leave CSV or $Inquire in public view
- one honest sentence about what the company actually does; if that sentence does not exist, mark `[OWNER INPUT REQUIRED]`

### About

License, legal name, American-led, named principals, Kabul base, LOI policy, no visa issuance, no safety guarantee.

Optional family sentence. No toast. No invented staff bios.

### Safety

The live page is thin and honest. Keep the honesty. Extend only with planning language already approved:

- itineraries change with road, weather, or access
- we do not sell fantasy itineraries
- travelers read their own advisory
- inherent risk; no safety guarantees

Do not add operational detail that creates liability (named checkpoints, convoy procedures, “real-time monitoring”).

### Visa / entry

Must stay consistent with the homepage. LOI for booked tours. We do not issue visas. Nationality exceptions stay `[OWNER INPUT REQUIRED]` until listed.

### Food / culture / dish pages

Do not paste the same four paragraphs onto every dish.

Each page needs: what the dish is, where it belongs geographically, how a traveler might encounter it on a journey. No “safe operational access” in metas or body.

Empty pages (example: Wardak Apples with an H1 and no body) get a short real paragraph or they stay unpublished. Do not fill them with boilerplate.

Do not list a restaurant unless the owner has said it is current and public.

### Hotels

References, not guarantees. Do not write “pinnacle of luxury” or invent stars. “Formerly Serena” stays only if the owner keeps it.

### Footer / contact

Phone and WhatsApp stay. Do not “fix” the number because the digits look sequential.

Do not send people to `/provinces/` or `/regions/` while those URLs 404. Use `/destinations/` and live province slugs.

## 7. History and politics

Allowed: dated, checkable statements already on the site or in standard references (Bamyan Buddhas destroyed in 2001; Minaret of Jam ~65 m, late 12th century Ghurid; Herat Friday Mosque as a standing monument; Babur’s Gardens as Mughal and later restored).

Not allowed:

- fountains that “flowed uninterrupted for five centuries”
- Panjshir “refused to bend” to the Taliban (the valley was taken in 2021)
- calling the Herat citadel “Alexander’s fort” as if the standing walls are Macedonian. Soften: site associated with Alexander; standing fabric is later.
- Hajigak “2,700 m” — the pass is about 3,700 m. If you do not know a number, omit it.
- invented UNESCO adjectives beyond “UNESCO World Heritage” where that status is real (Band-e-Amir, Minaret of Jam, and the Bamyan cultural landscape are the usual safe set; do not spray UNESCO on everything)

- Do not write a new H1 that is only a slogan if the current H1 is the product name.

## 9. Process for agents

Before you write:

1. Open the live URL. Copy is judged against what is live, not against a previous draft.
2. Check this file’s locked table.
3. Check that every tour name you want to mention has a live slug in section 5.
4. If you need a fact that is not locked and not on the page, stop and mark `[OWNER INPUT REQUIRED]`.

When you propose a change, use this shape:

```
PAGE: /path/
CURRENT SECTION: …
ACTION: KEEP AS-IS | MINOR EDIT | REPLACE | ADD | DELETE
CURRENT TEXT: …
PROPOSED TEXT: …
REASON: …
PRIORITY: P0 | P1 | P2 | P3
CONTENT DEPENDENCY: none | OWNER INPUT
```

P0 = public falsehood, guarantee, CMS leak, 404 in a nav label, empty page with an H1.  
P1 = wrong tour pairing, boilerplate, thin Safety/FAQ.  
P2 = tone, spelling consistency, extra links.  
P3 = optional polish.

After you write, run this checklist:

- [ ] Any safety adjective that slipped in?
- [ ] Any tour name without a live slug?
- [ ] Any price, inclusion, or vehicle model I invented?
- [ ] Any quote or “stories” CTA?
- [ ] Any “visa included”?
- [ ] Any winter claim for Jam / Ghor?
- [ ] Any CMS leak (CSV, $Inquire, Inquire Days)?
- [ ] Does the page end on a live tour, custom expedition, or WhatsApp?
- [ ] Would this paragraph still be true next season if a road closed?

If the answer to the last question is no, rewrite.

## 11. Quick examples

Bad: “Read traveler stories.”
