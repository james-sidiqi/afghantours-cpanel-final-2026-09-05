# Development

## Stack
- Astro 4 + Tailwind
- CSV/Markdown content under `data/` and `src/content/`
- Inquiry handler: `public/tour-inquiry.php` (honeypot, email|WhatsApp, dry_run gated)

## Commands
See root `README.md` QA gate.

## Dist policy
`dist/` is generated by `npm run build` and **force-tracked** for cPanel. Never hand-edit. After source changes that affect HTML/assets, rebuild and commit dist in the same PR when shipping.

## Inquiry URLs
Use `src/lib/inquiry.ts`. Contact page parses **canonical query params first**.

## Dry-run PHP locally
```bash
php -r '
$_SERVER["REQUEST_METHOD"]="POST";
$_SERVER["HTTP_HOST"]="localhost";
$_SERVER["HTTP_ACCEPT"]="application/json";
$_POST=["dry_run"=>"1","name"=>"QA","email"=>"qa@example.com","flow"=>"general"];
require "public/tour-inquiry.php";
'
```
Production hosts reject open `dry_run` unless `AFGHANTOURS_DRY_RUN_KEY` matches.
